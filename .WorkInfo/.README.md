# shuvoCodes — VS Code Terminal Themes 🎨

> **Make Your VS Code Terminal Look Awesome!**

A powerful PowerShell-based terminal prompt customizer for VS Code on Windows. Displays Git branch, Git status indicators, Python venv info, and project folder — all with beautiful themed colors.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🪟 **Windows Support** | Fully built for Windows PowerShell |
| 🌿 **Git Branch Display** | Shows current branch name in the prompt |
| ✅ **Git Status Indicators** | Clean/dirty working tree at a glance |
| 📁 **Project Folder Info** | Current folder name always visible |
| 🐍 **Python Venv Support** | Shows active `.venv` name |
| 🎨 **Multiple Themes** | 9 built-in themes to choose from |
| ⚡ **Easy Install** | One-command install via PowerShell |

## 🚀 Installation

### Method 1 — Install from GitHub (Recommended)

Open **PowerShell** in VS Code terminal and run:

```powershell
irm https://raw.githubusercontent.com/shakhawat-hossain-shuvo/shuvoCodes/main/install.ps1 | iex
```

> This downloads and sets up everything automatically.

---

### Method 2 — Manual Install

**Step 1:** Clone the repository

```powershell
git clone https://github.com/shakhawat-hossain-shuvo/shuvoCodes.git
cd shuvoCodes
```

**Step 2:** Run the installer

```powershell
.\install.ps1
```

**Step 3:** Reload your terminal or run:

```powershell
. $PROFILE
```

## 🎨 How to Change Themes

After installation, use the `Set-TerminalTheme` command:

### Change to a specific theme:

```powershell
# Matrix (Green hacker style)
Set-TerminalTheme -Theme Matrix

# Cyberpunk (Neon cyan)
Set-TerminalTheme -Theme Cyberpunk

# Dracula (Purple gothic)
Set-TerminalTheme -Theme Dracula

# One Dark Pro (Warm yellow)
Set-TerminalTheme -Theme OneDarkPro

# Nord (Arctic blue)
Set-TerminalTheme -Theme Nord

# Tokyo Night (Synthwave purple)
Set-TerminalTheme -Theme TokyoNight

# Minimal Dark (Clean white)
Set-TerminalTheme -Theme MinimalDark

# Solarized Dark (Teal green)
Set-TerminalTheme -Theme SolarizedDark

# Retro Green (Old school CRT)
Set-TerminalTheme -Theme RetroGreen
```

### See all available themes:

```powershell
Get-TerminalThemes
```

### Preview a theme without applying:

```powershell
Show-ThemePreview -Theme Cyberpunk
```

### Reset to default PowerShell prompt:

```powershell
Reset-TerminalTheme
```

## 🔧 What the Prompt Shows

After install, your terminal prompt will look like this:

```
[shuvoCodes@Windows]-[ my-project ]-[ (.venv) ]-[ 🌿 main]
→ ▌
```

| Segment | Meaning |
|---|---|
| `shuvoCodes@Windows` | Username @ Machine |
| `my-project` | Current project folder |
| `(.venv)` | Active Python virtual environment |
| `🌿 main` | Current Git branch |
| Color of `→` | Green = clean, Red = uncommitted changes |

## 🛠️ Uninstall

To remove shuvoCodes and restore default prompt:

```powershell
Reset-TerminalTheme -Uninstall
```

Or manually remove the lines added to your `$PROFILE`:

```powershell
notepad $PROFILE
```

Delete the lines between `# shuvoCodes START` and `# shuvoCodes END`, then save.
